# PersonaDNA

## AI-Powered Candidate Verification and Trust Analysis

PersonaDNA is an AI-powered candidate verification platform designed to analyze resumes, validate candidate claims, connect claims with supporting evidence, and generate an intelligent trust and risk assessment.

The goal is to move beyond traditional resume screening by creating an evidence-based candidate profile.

---

## What PersonaDNA Does

PersonaDNA analyzes candidate information and attempts to establish relationships between:

Resume Claims → Skills → Projects → GitHub Evidence → LinkedIn Evidence → Trust Analysis

Instead of relying only on what a candidate claims on a resume, PersonaDNA focuses on available evidence and consistency.

---

## Key Features

- Resume-based candidate analysis
- Candidate identity analysis
- Claim extraction and analysis
- Evidence mapping
- Skill mapping
- Project matching
- GitHub-based evidence analysis
- LinkedIn integration support
- Confidence scoring
- Risk analysis
- Candidate intelligence
- AI-generated insights
- Trust-oriented candidate reporting
- Interactive dashboard
- Visual trust graph
